# Potato Leaf Classifier Landing Page

A static React JS landing page design for a Machine Learning project that classifies potato leaves into three classes:

- Healthy
- Early Blight
- Late Blight

## Included sections

- Hero Section
- About Section
- How It Works Section
- Features Section
- Visual Preview Section
- Developer Section
- Footer

## How to run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes

- No React state is used.
- No click events are required.
- No backend or ML integration is included.
- The call-to-action button is design-only.
- Background and preview graphics are included as local SVG assets in `public/assets`.
